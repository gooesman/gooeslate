导入与导出

备份服务配置和使用习惯，或迁移到另一台电脑。

导出配置
包含 API 密钥和授权信息
默认不包含翻译、识别、语音密钥和欧路授权。

导出当前已保存的设置，未保存的更改不会包含在文件中。

勾选后，密钥和授权将以明文保存在配置文件中，请妥善保管。

自定义请求头和请求体也会导出，请检查其中是否填写了敏感信息。

导入配置
选择配置文件
支持鹅译导出的 JSON 配置（含旧版配置）。选择后先预览，再确认导入。
确认导入会替换当前已保存的服务、默认操作与快捷键；取消不会更改任何设置。

开机自启为本机设置，不随配置导入更改。
